# ABP-IA-entornos-virtuales-2026
Estudio piloto (N=5) que analiza las percepciones, niveles de adaptabilidad y conductas prácticas de estudiantes universitarios en modalidad virtual respecto al uso ético y reflexivo de la Inteligencia Artificial al resolver casos prácticos bajo la metodología de Aprendizaje Basado en Problemas (ABP).
